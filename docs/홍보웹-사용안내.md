# GL PROMO — 이용자 본인 계정 홍보

주소: https://hz-production-d530.up.railway.app/promo/

## 운영자

/admin → 홍보 회원·초대에서 이름과 유효기간만 지정해 1회용 웹 이용 초대를 만듭니다. 방 선택이나 10개 제한은 없습니다. 초대 링크를 해당 이용자에게 직접 전달합니다. 운영자의 게임 봇 인증 정보는 이용자 홍보에 사용하지 않습니다.

회원 사용 허용을 해제하면 해당 회원의 웹 세션·자동 홍보·실행 중인 연결을 중지합니다. 기록과 회원은 삭제하지 않습니다.

## 이용자

1. 처음에는 초대 링크를 열고 카카오 QR 로그인을 선택합니다.
2. 서버가 본인 계정으로 선택한 방에 전송한다는 안내에 동의하고 QR 코드를 만듭니다.
3. 본인 휴대폰 카카오톡으로 스캔한 뒤 기기 연결을 직접 승인합니다. 카카오 비밀번호를 이 사이트에 입력하지 않습니다. QR·인증번호를 다른 사람에게 공유하지 않습니다.
4. 본인 카카오 계정의 전체 채팅방 목록을 불러옵니다. 다른 이용자나 운영자 계정의 방 목록은 표시하지 않습니다.
5. 방 목록 위의 공통 홍보 문구를 한 번 저장합니다. 계정당 문구 하나를 모든 현재·향후 방이 공유하며, 문구 수정은 모든 방의 다음 전송부터 적용됩니다. 문구 저장 → 20분/30분 선택 → 방 이름 옆 ON. 20분은 매시 00·20·40분, 30분은 00·30분(한국 시각)의 첫 실행 시점에 전송합니다. 켠 시각 이후 다음 슬롯부터 전송하며 예약 시작 시간은 없습니다.
6. 재방문할 때는 카카오 QR 로그인으로 동일 계정에 접속합니다. 처음 연결된 계정만 초대 없이 재로그인할 수 있습니다. 이전에 웹 아이디·비밀번호로 가입한 회원은 이전 웹 계정으로 로그인 후 QR을 연결할 수 있습니다.

문구는 이용자 계정마다 하나이며 다른 이용자와 공유하지 않습니다. ON/OFF·간격·기록은 방마다 독립적입니다. 공통 문구 삭제는 해당 계정의 모든 방을 OFF로 바꿉니다. 이전 방별 문구가 하나로 동일하면 자동으로 공통 문구로 옮기고, 여러 문구가 다르면 기존 기록을 보존한 채 공통 문구를 새로 저장해야 전송합니다. 홍보는 QR로 연결한 해당 이용자의 계정으로 전송합니다. 웹 로그아웃만 하면 ON 상태인 홍보는 계속되며, 중지는 OFF 또는 카카오 연결 해제를 사용합니다. 연결 해제는 이 서버의 인증 토큰을 제거하고 자동 전송을 멈춥니다. 카카오톡 기기 목록에서도 필요에 따라 연결된 기기를 직접 해제할 수 있습니다.

연결을 해제해도 계정 연결 이력 ID는 재로그인을 위해 남습니다. 인증 토큰 원문은 웹 응답·로그·파일로 내보내지 않고 사용자 ID에 결합된 AES-256-GCM 암호문으로 PostgreSQL에 보관합니다. 기존 GL_SESSION_SECRET을 암호화 키 파생에도 사용합니다. 이 비밀값을 변경하면 기존 연결을 해독할 수 없어 QR 재연결이 필요합니다.

## 방 이름

방 제목 메타데이터(type 3)를 우선하며 보이스룸·라이브 제목은 방 제목으로 쓰지 않습니다. CHATINFO 응답에 ID가 없어도 요청한 방과 연결하고, 오픈채팅은 링크 정보를 추가 조회합니다. 방 목록은 보통 30초, 상세 이름은 5분 캐시를 사용합니다. 아직 이름을 확인하지 못한 방은 이름 확인 중과 ID 일부를 표시합니다.

## 보존 및 검증 한계

기존 게임·코인·주식·출석 테이블은 초기화하지 않습니다. 이용자별 연결·방·전송 기록 테이블을 추가합니다. 이전 버전에서 운영자 봇으로 보내던 회원 소유 자동 홍보는 새 버전 시작 시 중지하며, 기록은 보존합니다. 운영자 직접 설정 홍보는 유지합니다.

이 연결은 기존 KakaoForge의 QR/기기 연결 방식이며 공식 카카오 로그인 REST API와 다릅니다. 공식 메시지 API는 임의의 모든 기존 채팅방으로 보내는 기능을 제공하지 않습니다. 카카오 서버의 기기 연결 허용 여부에 따라 QR 인증이나 방 조회가 실패할 수 있습니다. 실제 휴대폰 QR 승인과 실계정 전송은 이용자가 직접 확인해야 합니다.
