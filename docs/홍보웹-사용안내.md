# GL PROMO 홍보 전용 웹

주소: 기존 서비스 주소 뒤 `/promo/` (운영: https://hz-production-d530.up.railway.app/promo/).

## 운영자가 회원 초대하기

1. `/admin`에 기존 관리자 계정으로 로그인합니다.
2. **홍보 관리**에서 사용할 방의 홍보 허용을 켜고 저장합니다.
3. **홍보 회원·초대**에서 받을 사람의 이름, 링크 유효기간, 허용할 방을 선택합니다. 해당 방의 소유자·관리자인지 운영자가 확인한 사람에게만 권한을 부여합니다.
4. 1회용 초대 링크를 만들어 그 사람에게 직접 전달합니다. 링크는 한 번만 표시되며 공개 게시하지 않습니다. 분실하면 초대를 취소하고 새로 만듭니다.
5. 홍보 회원 목록에서 방 권한을 바꾸거나 계정을 중지할 수 있습니다. 권한을 잃은 회원의 자동 홍보는 중지됩니다.

회원은 초대 링크에서 아이디, 표시 이름, 12~128자 비밀번호를 설정합니다. 초대는 1·3·7일 중 선택한 기간에 한 번만 사용할 수 있습니다. 홍보 계정과 기존 전체 관리자 계정은 별개입니다.

## 회원이 홍보 사용하기

- 로그인하면 봇에서 수집한 모든 채팅방 이름이 표시됩니다. 아직 수집하지 않은 방은 새로고침 시 봇의 방 목록에서 가져옵니다. 권한이 없는 방은 이름과 권한 대기 안내만 보이며, 문구·기록·제어는 허용되지 않습니다.
- 사용할 방에서 **문구 · 기록 보기**를 눌러 문구를 저장합니다. 전송 간격은 **20분 / 30분** 중 선택하며 OFF 상태에서도 선택이 저장됩니다.
- **방 이름 옆 ON/OFF**로 자동 홍보를 켜거나 끕니다. ON 직후 즉시 전송하지 않고 다음 정해진 시각부터 작동합니다.
- 한국 시각 기준 20분은 매시 **00·20·40분**, 30분은 매시 **00·30분**입니다. 예약 시작 시간 입력은 없습니다. 자동 실행은 해당 분의 첫 처리 시점(일반적으로 10초 이내)에 전송을 시도합니다.
- OFF는 다음 전송부터 중지합니다. 이미 전송 중인 메시지를 취소하지는 않습니다.
- 지금 전송은 확인창을 거친 뒤 실행되며 최근 전송 후 5분 이내에는 중복 실행을 제한합니다. 자동 홍보 시간표는 바뀌지 않습니다.
- 같은 방을 맡은 회원은 문구와 ON/OFF 상태를 공유합니다. 전송 기록에는 내 계정으로 실행한 기록만 표시됩니다.
- 계정 중지·방 권한 해제·봇 잠금 상태에서는 자동 전송하지 않습니다. 연결이 끊겼던 동안의 홍보를 몰아서 보내지 않습니다.
- 비밀번호 변경 시 모든 기존 홍보 로그인 세션이 만료됩니다. 비밀번호 분실 시 운영자에게 문의합니다.

## 운영 및 보존

기존 `DATABASE_URL`과 `GL_SESSION_SECRET`을 사용하므로 새 환경변수는 필요하지 않습니다. 회원·초대·세션·권한 테이블을 추가하며 기존 게임·주식·코인·출석 기록과 설정을 초기화하지 않습니다. 문구·권한 변경은 감사 기록에 남습니다. 비밀번호 원문·초대 토큰 원문은 DB에 저장하지 않습니다.

방 목록은 최근 수집한 정보와 기존 DB 기록을 함께 표시하므로 이미 나간 방이 기존 기록으로 남아 있을 수 있습니다. 이름을 못 가져온 방은 ‘채팅방’으로 표시됩니다. 메시지 전송 실패 시 기록을 남기며 같은 시간대에 자동 재시도하지 않습니다.
