# 채팅 순위 이미지

`!채팅순위`는 기존 `gl_manage_chat_counts`의 방별 누적 채팅 횟수를 조회하여 TOP 10 가로 막대그래프 PNG를 전송합니다. 1등은 금색, 2등은 은색, 3등은 동색이고 나머지는 회색입니다. 하단에는 명령 실행자의 현재 닉네임, 전체 집계 내 순위와 횟수가 표시됩니다. TOP 10 밖의 사용자도 자신의 순위를 확인할 수 있습니다.

`!채팅순위전체`는 기존 글 목록을 유지합니다. 방 관리 활성화와 권한 정책도 유지하며, 출석 이미지를 먼저 보낸 후 안내 글을 보내는 기존 동작은 바꾸지 않습니다.

한 번의 읽기 전용 SELECT로 TOP 10과 개인 순위를 같은 DB 스냅샷에서 가져옵니다. 순위는 기존 정책인 `count DESC,user_id ASC`를 사용합니다. 동률은 사용자 ID 순서로 구분합니다. 다른 방의 기록은 포함하지 않습니다. BIGINT 횟수는 문자열과 BigInt로 처리해 큰 숫자의 정밀도를 유지합니다. 기준일은 Asia/Seoul입니다. 기록이 없는 방에는 빈 상태 이미지를, 집계되지 않은 사용자에게는 `미집계 · 0회`를 표시합니다. 긴 이름은 말줄임합니다.

이미지는 1200×1370이며 승인된 예시 배치를 사용합니다. 텍스트·막대·금은동 색상·현재 날짜·개인 통계는 요청마다 동적으로 그립니다. 포함된 Noto Sans KR 글꼴과 기존 resvg를 사용합니다. 렌더링은 동시에 두 건, 대기는 최대 16건으로 제한합니다. 동일 방·사용자의 동시 중복 요청은 안내만 보냅니다.

기존 사진 업로드 어댑터를 확장하여 파일명과 크기를 전달합니다. 출석용 기본 크기와 파일명은 그대로입니다. 업로드 완료 응답을 확인하고 임시 파일은 성공·실패 모두 정리합니다. 이미지 생성·전송 실패 시 기존 TOP 10 글 목록으로 안내합니다.

추가 패키지·환경변수·DB 변경은 없습니다. 최신 main으로 빌드·재배포하고 기존 봇을 재시작하면 적용됩니다. 기존 DATABASE_URL, 로그인된 봇 연결, 관리 활성화 및 임시 폴더 쓰기 권한이 필요합니다. 실제 카카오톡 수신은 운영 재배포 후 확인해야 합니다.
