# Windows PowerShell — DB 없이 !k / !id / !핑

`bulk-kick.js`는 기존 KakaoForge `dist/`와 카카오 인증 파일만 사용합니다. PostgreSQL, `DATABASE_URL`, 전체 카카오톡 매니저 게임 및 관리 웹은 필요하지 않습니다.

## 준비

프로젝트 폴더에서 한 번 설치/빌드합니다.

```powershell
cd C:\KakaoManager-PC
git pull origin main
npm.cmd ci
npm.cmd run build
```

PC용 카카오톡 계정의 인증 파일이 `auth.json`에 저장되어 있어야 합니다. 별도 계정 인증 파일이라면 PowerShell에서 환경변수를 설정하세요.

```powershell
$env:KAKAO_AUTH_PATH = ".\auth-junggae.json"
```

이 명령은 현재 PowerShell 창에만 적용됩니다. 계정의 인증 파일을 GitHub나 채팅방에 올리지 마세요. 동일 계정이 Railway에서 실행 중이면 한쪽을 중지해야 합니다.

## 실행

```powershell
node .\bulk-kick.js --room 채팅방ID
```

이 모드는 **명시한 하나의 채팅방**에서만 채팅 명령을 처리합니다. PC 로그인 계정이 그 방의 방장 또는 부방장이면 강퇴 API를 이용할 수 있습니다.

## 채팅방에서 입력

| 명령어 | 설명 |
| --- | --- |
| `!핑` | PC 봇이 연결됐는지 확인 (누구나) |
| `!id` | 명령 사용자의 사용자 ID 표시 |
| `!id @실제멘션` | 멘션된 대상의 ID 표시 (방장·부방장·PC 봇만) |
| 상대방 메시지에 답장 `!id` | 원본 작성자 ID 확인 (방장·부방장·PC 봇만) |
| `!k 사용자ID` | 지정 ID 강퇴 요청 |
| `!k @실제멘션` | 멘션 대상 강퇴 요청 |
| 상대방 메시지에 답장 `!k` | 원본 작성자 강퇴 요청 |
| `!일괄강퇴` | 기존 기능. PC 봇 계정에서만 사용 가능 |

단일 강퇴 `!k`는 채팅방의 방장·부방장 또는 PC 로그인 봇 계정이 실행할 수 있습니다. 또한 **실제로 강퇴 명령을 전송하는 PC 로그인 계정** 자체에도 방장·부방장 권한이 필요합니다. 본인 또는 방장·부방장은 대상으로 지정할 수 없습니다.

참고: DB 없이 나간 사람을 지정하려면 숫자 사용자 ID를 알고 있어야 합니다. `!k 사용자ID`를 시도할 수 있지만 서버가 이미 나간 사람을 강퇴 처리할 수 있는지와 지속적인 재입장 차단 효과는 검증되지 않았습니다. **봇이 작성한 과거 퇴장 알림**에 대한 답장은 DB로 원래 퇴장자를 연결하지 않으므로, 퇴장자 식별 방법으로 지원하지 않습니다.

## PowerShell 창에서 직접 입력

프로그램이 켜진 상태에서 입력하세요.

```text
NEXI-PC> !핑
NEXI-PC> !id
NEXI-PC> !k 12345678901234567
NEXI-PC> !일괄강퇴
NEXI-PC> 종료
```

PowerShell에서 `!id`는 PC 로그인 봇 계정의 ID를 출력합니다. `!k`에는 정확한 숫자 대상 ID를 써야 하며, 멘션이나 답장은 채팅방 명령에서만 지원합니다.

## 테스트

```powershell
node --test test/pc-commands.test.js
```

모의 카카오톡 서버만 사용하는 로컬 테스트입니다. 실제 강퇴는 수행하지 않습니다.
