# 입장 인사말의 경고 변수

방장·부방장은 다음과 같이 설정할 수 있습니다.

```
!입장변경 (멘션)님 환영합니다!
경고 (경고횟수)개
경고사유: (경고사유)
```

- `(경고횟수)`와 `(경고사유)`는 해당 방의 해당 회원에게 남아 있는 경고를 조회합니다.
- 삭제·초기화된 경고는 제외합니다. 경고가 없으면 횟수는 `0`, 사유는 `없음`입니다.
- 사유는 최신 경고부터 줄바꿈으로 표시합니다. 같은 사유로 경고를 여러 개 받았다면 각 경고의 사유를 각각 표시합니다.
- 기존 변수와 기본 입장 알림은 그대로 사용할 수 있습니다. `!입장변경 기본`으로 초기화합니다.
