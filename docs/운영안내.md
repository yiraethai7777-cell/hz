# 운영 안내

## Railway

기존 봇 서비스와 PostgreSQL을 유지합니다. 현재 인증 파일 복원·빌드·hz-new.js 실행 명령은 그대로 사용할 수 있습니다. 웹은 같은 프로세스에서 Railway PORT에 바인딩합니다. 별도 데이터베이스와 카카오 인증은 필요하지 않습니다.

Networking에서 HTTPS 도메인을 연결하고 서비스 PORT로 보내세요. 접속 경로는 /, /admin, /health입니다. 공개 전 /api/admin/rooms가 로그인 없이 401을 반환하는지 확인하세요.

기존 DATABASE_URL, KAKAO_AUTH_B64, KAKAO_AUTH_PATH는 수정하지 마세요. 실제 auth.json·.env·.env.admin.local은 업로드하지 마세요.

## 관리자 최초 설정

1. 본인 PC에서 저장소 폴더를 열어 `node scripts/admin-setup.js`를 실행합니다.
2. 본인만 아는 12자 이상 비밀번호를 두 번 입력합니다. 입력은 화면에 표시되지 않습니다.
3. 생성된 `.env.admin.local`을 본인이 열어 Railway Variables에 GL_ADMIN_USERNAME, GL_ADMIN_PASSWORD_HASH, GL_SESSION_SECRET 세 값을 직접 추가합니다.
4. 해당 서비스가 재배포된 뒤 /admin에서 계정 admin과 설정한 비밀번호로 로그인합니다.
5. 이 파일을 채팅·GitHub·공유 ZIP에 넣지 마세요. 계정 설정 전에는 관리자 API가 잠겨 있습니다.

비밀번호는 scrypt 해시로 저장하고 세션은 HttpOnly·SameSite=Strict 쿠키, HTTPS Secure 속성, 8시간 만료를 사용합니다. 변경 요청에는 세션·CSRF 토큰·같은 출처 검사를 모두 적용합니다. 로그인은 15분 동안 5회까지 허용합니다. 잘못된 시도가 계속되면 15분 후 다시 로그인하세요. GL_SESSION_SECRET을 바꾸면 기존 쿠키 서명이 무효가 됩니다.

공개 오픈채팅 링크가 있으면 GL_OPENCHAT_URL에 https://open.kakao.com/... 주소를 설정하세요. 없으면 사이트에 이용 안내 버튼이 표시됩니다.

- !펫장착 최고, !레벨, !내정보

- 일반 사용자 !코인지급, !게임중지 권한 거절 확인
- 장중 !주식검색 → !주식시세 → !주식구매/판매, 장외 거래 거절 확인

- !랭킹공개 별명 → 공개 사이트 순위 / !랭킹비공개 → 제거

홍보 테스트는 본인이 관리하는 테스트방에만 하세요. 실제 사용자에게 자동으로 테스트 홍보를 보내지 않습니다. 본인 ID와 방 ID는 관리자 화면에만 표시됩니다.

## 통계 범위와 제한

오늘 활동은 새 기능 적용 이후 gl_game_events에 기록된 코인 변화가 있는 게임 활동을 집계합니다. 이전 활동을 임의로 복원하지 않습니다. 낚시 순위는 현재 인벤토리 마릿수이며 누적 포획 기록이 아닙니다. 사용자 수와 코인 합계는 등록 지갑 기준입니다. 아직 게임 지갑과 연결되지 않은 과거 points는 첫 이용 때 합산됩니다. 공개 코인 랭킹은 연결 전 잔액도 함께 표시합니다.

관리자 게임 조회와 설정·홍보·공지 API는 실시간 DB를 조회합니다. 화면 새로고침 또는 해당 메뉴를 다시 열면 봇에서 바꾼 값이 반영됩니다. DB는 초기화하지 않으며 신규 테이블을 추가합니다. 일회성 지갑 연결 후 코인 이력은 LEGACY_GAME_MERGE로 식별할 수 있습니다.
