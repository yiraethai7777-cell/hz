# 프로필 변경 감지 ON/OFF

봇 관리자가 관리 기능이 켜진 방에서 사용합니다.

- `!프로필감지on`: 이 방의 닉네임·사진·오픈프로필 링크 변경 알림을 켭니다.
- `!프로필감지off`: 이 방의 변경 알림을 끕니다.

기존 감지 설정 명령과 같은 봇 관리자 권한을 사용합니다. 방장·부방장이나 지정 관리자라는 이유만으로 설정을 바꾸지는 못합니다. 기존 관리 도움말에도 두 명령을 추가했습니다.

설정은 기존 `hz_rooms.data.profileAlerts`에 방별로 저장되어 재시작 후 유지됩니다. 설정하지 않은 방은 기존과 동일하게 ON입니다. 다른 방, 게임·관리 작동 상태, 플레이어 데이터는 변경하지 않습니다. 별도 환경변수나 DB 마이그레이션은 필요 없습니다.

OFF는 채팅 수신 시 감지와 주기적인 멤버 검사에서 나오는 **변경 알림**을 모두 중지합니다. 프로필 관찰과 기록 저장은 계속되어 기존 `!프로필로그`를 유지합니다. OFF 중 이미 관찰한 변경을 ON 시점에 알림으로 다시 보내지 않습니다. ON 이후 처음 관찰되는 차이는 당시 최신 정보와 마지막 관찰 정보를 비교하는 기존 방식으로 처리합니다.

검사 도중 OFF로 바꾸는 경우에도 전송 직전 설정을 다시 조회합니다. 이미 전송을 시작한 메시지는 회수하지 않습니다. 관리 기능 자체가 중지된 방과 잠긴 방의 기존 동작은 그대로입니다.

최신 main으로 빌드·재배포 후 봇을 재시작하면 적용됩니다. 실제 운영 카카오톡 알림은 배포 후 확인해야 합니다.
