# NEXI 광물 채굴

명령: !광산, !채굴, !광물인벤, !광물판매 전체, !광물판매 철광석 2.

20초마다 1~3개 채굴하며 하루 한도는 없습니다. 채굴이 DB에 저장된 뒤 봇의 동일 메시지를 광질중. → 광질중.. → 광질중... → 결과로 수정합니다(각 단계 700ms). 수정 기능이 없거나 실패하면 별도 텍스트 결과를 보냅니다. 채팅 실패가 채굴/판매 결과를 되돌리지 않습니다.

광물/확률/개당 가격: 석탄 45%/100, 철광석 30%/250, 금광석 15%/700, 에메랄드 7%/1,800, 다이아몬드 2%/5,000, 고대수정 1%/15,000코인. 개수 1~3은 균등합니다. 기대 판매가는 채굴당 1,202코인으로, 기존 퀴즈 정답 10,000코인보다 작게 설정했습니다. 운영 지갑 분포나 장기 경제 균형을 검증한 수치는 아닙니다.

전용 hz_mining_players 및 hz_mining_actions만 추가하며 기존 게임 기록을 초기화하지 않습니다. 방/사용자별 광물·채굴 간격을 행 잠금으로 보호합니다. 메시지별 영수증과 결과를 저장하고 중복 요청은 거절합니다. 판매의 광물 차감, 기존 hz_wallets 지급, hz_coin_logs 기록은 같은 DB 트랜잭션으로 처리합니다. 기존 economy.ensureLinked를 통해 판매 전 구형 지갑을 연결합니다. 금액 계산은 BigInt/NUMERIC로 수행합니다. 게임 OFF/일반 사용자 방 잠금 상태에서는 채굴 명령을 실행하지 않습니다.

새 이미지나 외부 이미지 자산은 사용하지 않습니다. 기존 게임 초기화 기능은 광물 전용 초기화 기능으로 확장하지 않았으며, 광물 기록은 보존됩니다.

검증: 광물/명령 경로 10개 테스트에서 중복·재시작·소유권·판매 롤백·거액 지갑·100회 초과·잘못된 수량·전송 실패·수정 메시지 번호를 확인했습니다. 실제 PostgreSQL 다중 프로세스 부하/실제 카카오톡 메시지 수정은 별도 검증이 필요합니다.

전체 테스트 비교: 기존 기준선 421개(280 통과, 140 실패, 1 취소). 현재 442개(299 통과, 142 실패, 1 취소). 새 실패 2개는 실행 환경의 잘못된 임시 폴더 ENOENT였으며, 유효한 임시 경로로 해당 2개 파일 10개 테스트 재실행 시 모두 통과했습니다. 그 외 실패 이름은 기준선과 동일합니다. 이전 퀴즈 접기 디자인에 맞춰 관련 표시 기대값을 갱신했습니다. 전체 성공으로 주장하지 않습니다.
