# NEXI 광산 2

명령: !광산, !채굴, !광물인벤, !광물판매 [전체 또는 이름 수량], !곡괭이, !곡괭이강화, !채굴지 [장소].

광물 12종: 석탄 1,000 / 철광석 2,500 / 구리광석 1,800 / 은광석 4,500 / 금광석 7,000 / 석영 6,000 / 에메랄드 18,000 / 루비 25,000 / 사파이어 30,000 / 다이아몬드 50,000 / 미스릴 80,000 / 고대수정 150,000코인(개당). 기존 보유 광물도 새 가격으로 판매됩니다.

채굴 간격 20초, 수량 1~3개, 하루 제한 없음. 채굴 결과에서 하루 한도 문구는 제거했습니다. 같은 메시지에서 광질중.부터 광질중.....까지 약 5초 연출 후 결과로 수정합니다. 게임 저장은 연출 전에 커밋됩니다. 채굴의 수정 응답에는 5초 제한이 적용되며, 응답 지연·누락·중첩 실패 상태가 있으면 결과 텍스트로 대체하고 추가 수정을 중단합니다. 실제 연결이 끊기거나 프로세스가 종료되는 순간의 메시지 전달까지 보장하지는 않습니다.

곡괭이는 개별 아이템입니다. 나무는 기본 지급, 돌 60,000 / 철 180,000 / 강철 540,000 / 다이아 1,500,000 / 미스릴 3,600,000코인입니다. 이전 장비 구매 없이 원하는 곡괭이를 바로 살 수 있습니다. 구매한 곡괭이는 보유 목록에 남고, 현재보다 좋으면 자동 장착됩니다. !곡괭이장착으로 보유 장비를 바꿀 수 있습니다. 이미 보유한 아이템은 재구매/차감하지 않습니다. !곡괭이강화는 구매 안내만 표시합니다.

희귀 광물 가중치는 기본가중치 × (1+장착 등급×0.2×희귀도) × (1+장소보너스×희귀도)로 계산한 뒤 정규화합니다.

장소: 광산입구(기본), 깊은동굴(철 이상 장착, 보너스 0.5), 수정지대(다이아 이상 장착, 보너스 1). 이동은 무료이며 채굴 재사용 시간은 초기화하지 않습니다.

!상점은 곡괭이·낚싯대·씨앗·소모품으로 구분하고 하나의 명령 경로에서 한 번만 표시합니다. 기존 낚싯대/씨앗/소모품 구매 명령과 가격은 재사용합니다. 광물 판매의 숨은 공백·Hangul 숫자 엔티티를 정규화하며, 인수 없는 !광물판매는 전체 판매입니다. 오류 로그에 거절 사유를 추가했습니다.

기존 전용 테이블에 pick_level과 location만 추가합니다. 광물·기존 게임·코인을 초기화하지 않습니다. 구매는 행 잠금과 메시지 영수증으로 보호하며 코인 차감, 보유 목록·장착 변경, 거래 로그는 동일 트랜잭션입니다. 장소 변경과 채굴도 같은 사용자 행 잠금을 사용합니다. 가격은 사용자 요청으로 상향했으며 운영 경제 분포·장기 인플레이션 검증은 미실시입니다. 새 외부 이미지 자산은 사용하지 않습니다.

검증: 강화 잔액/롤백/중복/권한·장소 잠금·쿨다운 보존·재시작·확률 개선·판매 입력 정규화·상점 단일 응답·수정 시간 초과와 중첩 실패 응답을 테스트했습니다. 실제 PostgreSQL 다중 프로세스 부하 및 실제 카카오톡 수정 UI 검증은 미실시입니다.

최종 검증: 광산/상점/낚시 수정 복구 핵심 26개가 로컬 및 운영 파일 구성에서 모두 통과했습니다. 전체 451개 중 310 통과, 140 실패, 1 취소이며 기존 기준선과 실패 이름 집합이 같습니다. 빌드 통과.

구매 방식 전환: owned_picks를 추가해 이전 등급까지의 곡괭이를 기존 사용자 보유 아이템으로 이관합니다. 기존 코인·광물·거래 로그를 초기화하거나 다시 차감하지 않습니다. 낮은 장비를 장착해 장소 요건을 충족하지 못하면 광산입구로 이동하며 채굴 재사용 시간은 유지됩니다.

스크린샷 후 수정 보강: 운영 로그에 MODIFYMSG -303 거절이 반복됨을 확인했습니다. 일반 WRITE는 _enqueueSend를 사용하지만 수정은 직접 전송하던 경로여서, 수정도 같은 대기열에 연결했습니다. 연출 수정은 deadlineAt 이후 대기열에서 폐기해 늦은 진행 문구가 결과를 덮지 않게 합니다. 명시적인 -303 거절은 1.6초 후 최종 결과만 같은 메시지에 한 번 재시도하고, 대체 결과 WRITE의 명시적 -303도 한 번만 재시도합니다. 시간 초과 요청은 처리 여부가 불명확하므로 같은 진행 수정을 재전송하지 않습니다. 실제 카카오톡에서 수정 성공을 확인한 것은 아닙니다.

이번 검증: 빌드 및 핵심 32개 통과. 전체 457개 중 316 통과, 기존 140 실패, 1 취소. 기준선 대비 신규 실패 이름 없음.

메시지 정책: 수정 연출은 채굴에만 적용합니다. 낚시는 시작/끌어올림 메시지 없이 최종 결과를 바로 한 번 전송합니다. 농장 심기·수확의 5초 작업과 정산은 유지하되 완료 시 기존 메시지를 수정하지 않고 새 메시지로 안내합니다. 퀴즈·타자게임 등의 현재 일반 전송 경로와 관리 기능의 SDK 수정 API는 유지합니다.

메시지 수정 제거 검증: 낚시·농장 일반 전송과 채굴 유지 관련 33개 테스트 및 빌드 통과. 전체 458개 중 317 통과, 기존 140 실패, 1 취소이며 기준선 대비 신규 실패 이름은 없습니다. 실제 카카오톡 UI 검증은 별도입니다.
