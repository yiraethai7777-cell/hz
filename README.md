# HZ 봇 게임·관리 분리본

이 버전은 hz-bot.js 없이 실행됩니다. 해당 파일의 기존 게임·관리 기능을 각각의 모듈로 분리했습니다.
이전 ZIP 대신 이 버전을 사용하세요. 낚시는 사진 없이 텍스트로 출력하며 신규 등장 물고기는 20종입니다.

## 구조
- hz-new.js: 메인 초기화
- start.js: 실행 및 상태 확인 서버
- login.js: 인증 도구
- game/index.js: 게임 연결과 토글
- game/features.js: 낚시·펫·퀴즈·강화·준개 등 기존 게임 기능
- game/data.js: 물고기·펫·퀴즈 데이터
- game/commands.js: 최근 만든 주식·코인 명령 처리
- game/wallet.js, coin.js, members.js, trading.js: 지갑·송금·가입·주식 거래
- manage/index.js: 관리 명령과 관리 토글
- manage/features.js: 기존 관리·경고·프로필·홍보 기능
- manage/attendance.js: 최근 만든 출석·보상 처리
- shared/runtime.js, state.js, session.js: 공유 상태·DB 기록·이벤트 연결
- shared/router.js: 실제 클라이언트의 단일 메시지 수신 함수
- shared/db.js, help.js: DB 연결 및 명령어 안내
- src/: 카카오톡 연결 소스. fish-assets/는 더 이상 사용하지 않습니다.
- test/: 회귀 테스트
- docs/: 이전 버전 문서 보관. 옛 파일 경로는 현재 버전에 적용하지 마세요.

## 실행
Node.js 22.8 이상 또는 24에서 npm install 후 npm start.
검사: npm run build, npm test.
기존 Railway 환경 변수, DATABASE_URL, KAKAO_AUTH_PATH는 유지합니다.

## 작동
봇 계정에서 !게임작동을 입력하면 관리 작동 여부와 관계없이 게임을 켤 수 있습니다.
관리와 게임 토글은 봇 계정만 사용할 수 있습니다.
게임과 관리는 각각 독립적으로 켜고 끌 수 있습니다.
켜진 뒤 관리와 게임의 중지 설정은 독립적으로 유지됩니다.
!명령어는 해당 방에서 켜진 기능의 목록만 표시합니다. 관리와 게임이 모두 켜져 있으면 두 목록을 구분하여 함께 표시합니다. !명령어 관리 / !명령어 게임 / !명령어 주식으로 활성화된 기능별 목록을 확인할 수 있습니다. 더보기용 zero-width 공백 1,200개는 유지합니다.

삭제 알림은 삭제한 사람만 표시합니다. 원문은 새로 저장하거나 조회하지 않으며, 삭제만으로 자동 경고나 강퇴를 하지 않습니다.

## 검증 범위
기존 기능 함수 76개의 본문을 분리 전 코드와 비교했습니다.
변경은 공유 상태 접근 방식 및 이동한 낚시 이미지 경로입니다.
기존 DB 테이블명·스키마·게임 기록 처리 로직은 유지합니다.
빌드, JavaScript 28개 문법, 상대 경로 48곳, 테스트 11개 통과. 사진 전송 제거 및 기존 물고기 판매 보존 검증 포함.
테스트는 모의 DB를 사용하며 운영 PostgreSQL 및 실제 카카오톡 연결 검증은 아직 수행하지 않았습니다.
